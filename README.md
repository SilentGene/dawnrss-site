# DawnRSS website

The public website of DawnRSS (朝闻道RSS), a quiet, book-like RSS reader: the home page in three languages, the privacy policy, and the pages the account emails link to (`auth/`).

Served by GitHub Pages from the root of `main`. The pages are built in the app's repository (`python tool/publish_site.py`) and copied here; edit them there rather than here.
